## Características principales

- Arquitectura moderna (Astro + React + NestJS)
- Sistema de formularios inteligente con validación multicapa
- Envío de correos automatizado con templates personalizables
- Seguridad multicapa (API Keys, rate limiting, Helmet, CORS)
- Diseño responsive y animado
- Gestión de cursos educativos
- Optimización de recursos (WebP, fuentes optimizadas)
- Sistema de logging y monitoreo

## Rendimiento excepcional

- SSR con islands de React
- Rate limiting escalable (500 req/15min)
- Validación eficiente
- Protecciones de seguridad (HSTS, CSP)
- Imágenes WebP y fuentes optimizadas
- Limpieza automática de memoria
